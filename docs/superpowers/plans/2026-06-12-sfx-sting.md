# Restrained SFX Sting (Project E) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A single, restrained soft-impact SFX in the long-form Remotion timeline, synced to the **gold accent-rule wipe on the FIRST chapter card only** (chapter 1) — the cold-open → first-chapter beat. One hit per video. Self-stubs silent when no SFX asset is present.

**Decision (user, this session):** placement = **chapter-1 accent, one hit** (rejected: per-chapter = peppered; bookend intro+outro = too heavy for a slow doc).

**Timing (frame-exact, fps 30):** the hit lands at `introF + ms2f(chapters[0].startMs) + round(fps*0.18)` — i.e. the same `0.18 s` accent delay used by the gold rule in `ChapterCard.tsx:14`, on chapter 1's card.

**Architecture:** one optional `sfxSrc` prop + one gated `<Sequence><Audio></Sequence>` in `UntoldVideo.tsx`; one brand asset in Remotion `public/sfx/`; `build_props` sets the prop only when the asset exists. Long-form only; Shorts unaffected.

**PRECONDITION — do not start until both are true:**
1. The in-progress **`ChapterCard.tsx` accent work is committed** (the accent rule this syncs to currently lives in an uncommitted working-tree edit). This plan must NOT modify `ChapterCard.tsx`.
2. A soft-impact **SFX asset exists** at `engine/video/remotion/public/sfx/impact.wav` (user-supplied; a ~0.6–1 s low sub-boom, cleared/royalty-free). Until then the feature renders silent (self-stub) — shippable, just inaudible.

**Conventions:** `python3` only; absolute `engine.*` imports; pytest after each `engine/**.py` edit; feature branch `feat/sfx-sting`, never `main`; still/short render is the visual+audio check, never the 45-min gate.

## Task E1: `sfxSrc` prop + gated sting in `UntoldVideo`

**Files:** Modify `engine/video/remotion/src/types.ts` (add `sfxSrc?: string`), `engine/video/remotion/src/UntoldVideo.tsx` (the gated Sequence).

- [ ] **Add the prop.** In `types.ts`, add `sfxSrc?: string;` to `UntoldProps` (optional → renders without it).
- [ ] **Add the sting.** In `UntoldVideo.tsx`, add a single gated child inside `<AbsoluteFill>` (alongside the existing Narration/Captions sequences). It fires once, on chapter 1's accent wipe:
```tsx
      {/* One restrained impact, synced to the gold accent-rule wipe on the FIRST chapter
          card (the 0.18s delay matches ChapterCard.tsx). Self-stubs: no sfxSrc → no sound. */}
      {props.sfxSrc && props.chapters.length > 0 && (
        <Sequence
          from={introF + ms2f(props.chapters[0].startMs, fps) + Math.round(fps * 0.18)}
          name="SFX"
        >
          <Audio src={staticFile(props.sfxSrc)} volume={0.5} />
        </Sequence>
      )}
```
(`Audio`, `Sequence`, `staticFile`, `ms2f`, `introF`, `fps` are all already in scope in `UntoldVideo.tsx`.)
- [ ] **No test** (presentational/audio). Run `npx remotion still`/a short render with a placeholder `public/sfx/impact.wav` and confirm the hit lands on the chapter-1 accent and nowhere else. Commit: `feat(remotion): single restrained SFX on the chapter-1 accent`.

## Task E2: wire `sfxSrc` through `build_props` (self-stub)
