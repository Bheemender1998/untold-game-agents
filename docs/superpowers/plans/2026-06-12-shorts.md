# YouTube Shorts (Project B) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Produce standalone vertical (1080×1920, 30–50s) YouTube Shorts — own short script (hook + fact + payoff), vertical composition, 9:16 footage, mood-matched royalty-free music — without touching the long-form pipeline.

**Architecture:** Four independently-shippable pieces. B1 adds a `--short` script mode that emits a `mood`. B2 parameterizes the render (dimensions + composition id) and adds a self-contained `UntoldShort` Remotion composition (reusing only `Background`). B3 layers mood-matched music as a second `<Audio>`. B4 adds short-specific QC (dimensions + max-duration). Each piece is its own branch/PR via `ship-video-change`.

**Tech Stack:** Python 3 (produce/QC), Remotion/React (composition, in `.venv-video`-driven render), Pexels (footage), Kokoro (TTS), pytest.

**Spec:** Project B in `docs/superpowers/specs/2026-06-12-overnight-and-shorts-design.md`.

**Conventions:** `python3` only; absolute `engine.*` imports; run `python3 -m pytest tests/ -q` after each `engine/**.py` edit (hook enforces); feature branch per piece, never `main`; integrity gate (ADR-0005) — short scripts go through the SAME fact-gate as long-form.

---

## Decisions locked by this plan (surfaced during exploration)
1. **Self-contained vertical composition.** New `UntoldShort.tsx` + `ShortCaptions.tsx`; reuse `Background` only. The shared long-form components (`Intro/ChapterCard/Outro/Captions`) are NOT touched — zero regression risk, at the cost of a little duplication.
2. **Real portrait footage**, not center-crop: `footage.py` gains a `portrait` flag (Pexels `orientation=portrait`).
3. **`mood` is emitted by the short-script writer** and stored on the idea (new optional schema field). Music + voice both read it.
4. **Shorts skip the long-form metadata chain.** Short produce writes a minimal metadata (title from the idea + a `#Shorts` description). Full Shorts SEO metadata is out of scope this cut.
5. **Music selection is deterministic, rotated by idea id** (no `random`), self-stubs to silent when the library is empty.
