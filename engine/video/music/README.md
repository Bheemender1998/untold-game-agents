# Background music library (Shorts)

Drop cleared, royalty-free tracks (.mp3 / .wav) into the mood subfolder. The render
selects a track matching each Short's `mood`, mixed low (~0.12–0.15) under the narration.
`manifest.json` (generated from these folders) maps mood → tracks + license attribution.

## Moods → content
- **tense/**       investigations, scandal, controversy, tragedy build-up
- **triumphant/**  underdog wins, vindication, redemption
- **somber/**      loss, tragedy aftermath, end of an era, walking away
- **hype/**        fast montage intros, high-energy reveals, what-ifs

## Where to download (all free + cleared)
- YouTube Audio Library — studio.youtube.com → Audio Library → Mood + Genre:Cinematic (mostly NO attribution)
- Pixabay Music — pixabay.com/music (CC0, NO attribution)
- Uppbeat — uppbeat.io/music/category/cinematic (free tier needs credit)
- Incompetech / Kevin MacLeod — incompetech.com (CC-BY, needs credit)

Tracks needing credit: note the attribution string; it gets appended to the video description.
